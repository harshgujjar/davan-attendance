📲 Install on the kids' devices

📱 Kids phone (next to the Google Home)
  1. On the spare Android phone open in Chrome → download → install (allow "Install unknown apps" for Chrome once).
  2. Open Home Class → allow the microphone → allow "Display over other apps" (so class time opens it by itself).
  3. Here: ➕ Add a device → type the 6-digit code on the phone.
  4. Google Home app → your speaker → ⚙️ → Paired Bluetooth devices → Enable pairing mode. On the phone: Bluetooth → pick the speaker. The voice now comes from the Google Home.
  5. Keep the phone on charge next to the speaker with the app open. That's all - it updates itself.
📺 Google TV
  1. On the TV: Google Play → install Downloader (by AFTVnews).
  2. TV Settings → System → About → press Android TV OS build 7 times (developer mode) → Settings → Apps → Security → allow Downloader to install apps.
  3. In Downloader type → Install → Open.
  4. Here: ➕ Add a device → type the code with the remote. The TV shows the live class big, and the kids can also practise with the remote (number keys on screen).
