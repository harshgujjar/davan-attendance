DAVAN PC DOCTOR - MY NOTES  (edit on GitHub: pcdoctor/src/notes.txt - it reaches every PC with the next update)
Last written: 05 Nov 2026.  Tap "Copy notes" below to paste them anywhere.

=== 1. WHAT IS WHAT ===
- PC Doctor Agent = the background part (a Windows service). It measures this PC every minute and sends it to the Console. It works with no one signed in.
- Tray = this window + the icon near the clock. Closing the window only hides it - nothing stops. If the icon disappears it comes back by itself within 10 minutes.
- Console = the web page lab.html (all PCs, fixes, settings). Open it from the tray: "Open Console" button, or tray icon -> right-click -> Open Console.
- Tabs here: This PC (facts, buttons) | Updates | Notes | All PCs + Ask AI (only on the Super Admin laptop).

=== 2. PASSWORDS ===
- Tray password (to open this window, Uninstall, Fix / Update from pendrive): 2531 - changeable on the Console (Settings).
- Console password: its own password, set in the staff app -> PC Doctor Settings. It locks after wrong tries.
- Deep Freeze password: only you know it. NEVER type it in a chat. (If PC Doctor ever uses it, you enter it once in the Console Settings.)

=== 3. INSTALL ON A NEW PC (about 2 minutes) ===
1. Name the PC first: A5 = Lab 1, B5 = Lab 2, PUC2 = PUC office ... (the letters in front choose the group).
2. Deep Freeze PC: set Boot THAWED and restart. Sign in as an administrator. Needs internet.
3. Right-click PCDoctor-Setup.cmd -> Run as administrator. 7 steps show; wait for "installed". Press any key.
4. Icon near the clock after 1-2 minutes. The PC shows on the Console in about 2 minutes.
5. Console -> New PCs: check name + group (Assign if asked).
6. Deep Freeze: set Boot FROZEN again.
No PCDoctor-Setup.cmd? Open Notepad, paste the 12 lines Claude gave, Save as -> All files -> PCDoctor-Setup.cmd. Or open this link in a browser and save:
  https://harshgujjar.github.io/davan-attendance/pcdoctor/PCDoctor-Setup.cmd

=== 4. IF THE ICON IS MISSING / THE TRAY WILL NOT OPEN ===
a) Wait 10 minutes - a task starts it again by itself.
b) Press Win + R, paste, Enter:   wscript "C:\ProgramData\DavanPCDoctor\tray-start.vbs"
c) If that says file not found (old version), paste instead:
   conhost --headless powershell -NoProfile -STA -ExecutionPolicy Bypass -File "C:\ProgramData\DavanPCDoctor\bin\tray.ps1"
d) Still nothing: run PCDoctor-Setup.cmd again as administrator. It is safe - the PC keeps its name, group, notes and history.

=== 5. IF PC DOCTOR SEEMS NOT WORKING (PC not on the Console, "off", old data) ===
1. Press Win + R, type services.msc, Enter. Find "Davan PC Doctor Agent". It must say Running / Automatic. If not: right-click -> Start.
2. Win + R, type taskschd.msc, Enter -> Task Scheduler Library -> "Davan PC Doctor" should exist.
3. Look at the logs:  C:\ProgramData\DavanPCDoctor\log   (loader.log = updates; agent logs). Send the last lines to Claude.
4. Tray -> This PC -> "Copy": copies the full report. Paste it to Claude.
5. Internet: on the PC open https://raw.githubusercontent.com/harshgujjar/davan-attendance/main/pcdoctor/lab-version.json in a browser. If it does not open, GitHub files are blocked on this network -> use the Update pendrive (section 7).
6. Last resort: run PCDoctor-Setup.cmd again (as administrator, PC Thawed).

=== 6. HOW TO OPEN COMMAND PROMPT / POWERSHELL ===
- Command Prompt: press the Windows key, type cmd, press Enter.  AS ADMINISTRATOR: type cmd, then right-click it -> Run as administrator (or Ctrl + Shift + Enter).
- PowerShell as administrator: Windows key, type powershell, right-click -> Run as administrator.
- To paste in the black window: right-click once (Ctrl + V also works on Windows 10/11).

=== 7. UPDATES ===
- Automatic: every start and every hour. Tray -> Updates -> "Update now" checks at once and shows a bar: looking -> downloading file x of y -> installing -> starting.
- The title bar shows the running version (PC Doctor v1.xx). "What's new" lists the changes.
- NO INTERNET / GitHub blocked -> UPDATE PENDRIVE:
  1. On a PC with internet: Console -> Rescue page -> "Make PC Doctor update pendrive" -> a zip downloads.
  2. Unzip it into the ROOT of a pendrive (you must see a folder called DavanUpdate).
  3. Plug it into the lab PC -> tray -> Updates -> "Update from pendrive" -> tray password.
  4. The bar shows file x of y; PC Doctor restarts by itself. (Needs PC Doctor 1.29 or newer already installed.)
- Deep Freeze PC: an update done while FROZEN is lost at the next restart (it downloads again at every start). To keep it, update while Thawed.

=== 8. DEEP FREEZE - HOW PC DOCTOR BEHAVES ===
- FROZEN: measuring, reports, verdict, light fixes (stop a hung program) all work. Light fixes last until restart.
- Fixes that must last (settings, clean-ups that change Windows) wait: Console Dashboard shows "Thaw needed: A5 (1 fix)".
- To run the waiting fixes by hand: Deep Freeze -> Boot THAWED -> restart -> PC Doctor runs them by itself -> alert "Thawed fixes done" -> Deep Freeze -> Boot FROZEN.
- Fixes that DELETE anything never run by themselves - only when you tap them on the Console.
- PCs without Deep Freeze: fixes run at once, no "Thaw needed".

Test step - does this PC have the command-line tool?
  1. Open Command Prompt (section 6).
  2. Type:  dir C:\Windows\SysWOW64\DFC.exe     and press Enter.
  3. Also try:  dir C:\Windows\System32\DFC.exe
  - A line with DFC.exe and a size = YES, it works with this Deep Freeze edition.
  - "File Not Found" in both = NO (this edition has no command line) -> use a weekly Thawed round by hand, or the full Deep Freeze edition.
  Also note: which Deep Freeze edition + version (open Deep Freeze -> About) and what hours the lab is open. Tell Claude the answers.

=== 10. OTHER BUTTONS ===
- Send report now / Check now: send a fresh full report / verdict within about a minute.
- Save report to pendrive: works with no internet (put DAVANLAB.key in the pendrive root once, then it also saves by itself when plugged in). Console -> Import reads it.
- Fix from pendrive: runs fixes you approved on the Console (Console -> Rescue page -> Make fix pendrive). Tray password asked.
- Name / group / notes: rename the PC (Windows renames at the next restart; a Frozen PC at a Thawed restart).
- Uninstall: tray password -> choose to remove MeshCentral too -> list of what is removed -> Yes. Not on a Frozen PC (Thaw first). The PC moves to Old PCs; Setup again brings it back.
