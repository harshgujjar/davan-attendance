One-time setup on this laptop
  1. Install the free VB-CABLE (vb-audio.com/Cable), then restart the laptop.
  2. Open Phone Link, link the college Android phone and turn on Calls (Bluetooth).
  3. Windows Settings → System → Sound → Volume mixer: Microsoft Edge → Output = CABLE Input; Phone Link → Input = CABLE Output (make one test call first if Phone Link is not listed). Other way: Sound settings → Input → set CABLE Output as the default microphone.
  4. Use Edge only for this page (everything Edge plays goes into the call). Edge Settings → System → Never put these sites to sleep: add this page.
  5. Edge Settings → Start, home → Open these pages: add this page, and set Edge to start with Windows - it then opens by itself every morning.
  6. On the phone in Davan Caller: queue a 🧪 test call to your mobile and turn Auto calling ON.
